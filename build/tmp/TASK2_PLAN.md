# Задача 2: звук игры AY -> ВИ53 (ветка splash, после fc3c9d9)

## Дизайн (решён по разведке 2026-09-22)
- **Мелодии**: отказаться от real-time MSX-пересчёта. Играть `src/msx_tunes_vi53.bin`
  (847 Б, готов; формат: +0 u16 N=6; далее 6 записей (u16 смещение блоба, u16 длина в
  кадрах); блобы = a8_tune_c64 Re-Pair, голос C всегда пуст). Плеер — тот же a8_tv, что
  у заставки (код в tools/a8_vec.py, fc3c9d9), но теперь в ОБЫЧной сборке (не release-only).
  Каналы: AY A -> счётчик 1, AY B -> счётчик 2, счётчик 0 не трогать (секундомер di).
  Играет ровно «длина в кадрах» тиков, потом глушит счётчики 1/2 и возвращает.
- **SFX**: рецепт Knight Lore (kl_sound_ay.py): msx_wr пишет в зеркало msx_ayregs (DS 16)
  вместо портов 0x15/0x14; раз в кадр (точка msx_frame_off, build/alien8_vec.asm:2673)
  msx_viflush: для счётчиков 1,2: канал B->1, C->2; канал A (слот 0) ворует свободный
  (сперва 2, потом 1), третий эффект отбрасывается; делитель = 13P + P/2 (kl-целое);
  громкость: порог 6/15, бит огибающей 0x10 = полный голос; шум R6 -> делитель R6*256;
  делитель < 64 -> тишина; управляющее слово (0x76/0xB6...) только при смене ВЛАДЕЛЬЦА
  (msx_viown), при возврате владельца кэш делителя msx_vidiv = 0xFFFF; тот же делитель —
  не писать; тишина = управляющее слово без делителя; порты: ctrl 0x08, c1=0x0A, c2=0x09
  (порты ПЕРЕСТАВЛЕНЫ!), out (c) нет — заглушка-stub (D3 port C9, ret на +2!).
- Мелодия и SFX не конфликтуют: msx_sfx_start отказывает во время мелодии (как в MSX).
  При старте мелодии: msx_viown[1],msx_viown[2]=0xFF + побить кэши.
- msx_silence/msx_stop (стоп-список AY) -> заглушить счётчики 1,2 тем же способом.
- Мелодия теперь НЕ ходит в vec_isr (голос C пуст) — правки vec_isr для мелодий не нужны.
